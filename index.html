Paano I-edit ang nilalaman ng Website

Ang buong website na ito ay nakapaloob sa iisang HTML file (`index.html`). Maaari mo itong palitan o dagdagan sa pamamagitan ng pag-edit ng JavaScript Code sa loob ng file.

Hakbang sa Pag-edit:

  1. Buksan ang index.html gamit ang Notepad, VS Code, o kahit anong text editor.
  2. Hanapin ang variable na const SITE_DATA = { ... } sa ibaba ng script tag.
  3. Palitan ang nilalaman ng announcements, lessons, o quiz.
  4. I-save ang file. Awtomatikong mag-uupdate ang website pag-refresh sa browser!
